Check Out Report

A check out report is complied at the end of the tenancy, once the tenant(s) have moved out we compile a report that goes through the condition and content against the original inventory and check in reports. At the end of the tenancy, the tenants(s) have to return the property in the same condition that it was originally let while allowing for fair wear and tear.

  • All Changes Are Noted
